# 教务管理系统（EduAdmin）

榆中县职业技术学校教务管理系统 —— 基于 Flask + SQLite 的局域网教务管理 Web 应用，覆盖**订书发书、排课、调课、超课时、夜自习、加班管理费、补助发放**等完整教务流程，单用户双角色（管理员 / 领导），数据全在本机，不出局域网。

## ✨ 功能总览

| 模块 | 核心能力 |
|---|---|
| **订书发书** | 按专业/学期/图书类别规划征订，教材库管理，发放统计 |
| **排课管理** | 班级 / 教师 / 教室三视图课表，互相联动，冲突自动检测 |
| **调课登记** | 免审批登记，顶课教师自动生成补助，统一按「调课」统计 |
| **超课时统计** | 有效周按自然周计算（整数、无小数点），4 周周期结算，请假扣减 |
| **夜自习管理** | Excel 排班导入，统计页集中修改，4 周结算补助 |
| **加班管理费** | 加班记录 + 管理费登记，发放时并入「管理」项目 |
| **补助发放** | 6 个项目、每 4 周一次，自动读取各模块数据 + 可手动修改 |
| **数据管理** | 统一导入、在线备份/恢复/重置、**单项数据删除**（17 类） |

其他：班级 / 教师 / 课程 / 教室 / 教材管理、停课/上课日、课时标准、学期管理、综合报表、操作日志、全局搜索、多主题。

## 📖 模块详解

### 1. 订书发书
- **征订计划**：按专业（1-6 学期）+ 图书类别规划，支持文化课（全校各班）/ 专业课（必须选专业）分类筛选，导出支持全部 / 分专业
- **教材库**：教材统一建档（ISBN/出版社/价格/库存），征订时支持内联「＋新建教材」
- **发书登记**：班级发书 / 教师教本两种类型，发放统计按班级汇总

### 2. 排课管理
- **三视图联动**：班级课表 / 教师课表 / 教室课表同一数据源，天然一致
- **数据来源**：以教务处 Excel 上传为准（数据管理 → 统一导入），课表支持手动调整（移动/删除）
- **冲突检查**：教师/班级同时段、教室占用自动检测，冲突时拒绝修改并回滚，前端明确提示
- **细节**：合班课去重统计、教师按任教科目排序（语文→数学→…→专业课）

### 3. 调课登记
- 免审批直接登记（状态直写生效）
- 顶课教师按节数 × 单价自动生成补助
- 统一按「调课」口径统计（不区分换课/看班），看课记录可导出

### 4. 超课时统计
- **有效教学周数按自然周计算，恒为整数、无小数点**：放假停课也按一整周计（不扣周数）；可在「停课/上课日」页查看，或学期管理中手动指定整数周数
- **无学科系数**：上一节算一节（课表周课时 × 有效周数 − 请假扣减 = 实际课时）
- **标准课时** = 职务周标准 × 有效周数（职务标准可配置）
- **超课时** = 实际 − 标准（超过部分才计），× 单价 = 金额
- **两种视图**：整学期统计 + 每 4 周周期结算（周期自动切分，末周期按实际周数）
- 支持 Excel 导出（超课时统计表 + 明细）

### 5. 夜自习管理
- **排班页只读**：展示标准安排表，修改统一在统计页
- **统计页「先修改、统一保存」**：改动本地缓存，一次提交生效
- **列头操作**：整日不排（软标记可恢复）/ 恢复该日 / 整列复制其他日期的排班
- **Excel 导入**：两步导入（选 sheet、起始日期与周数），未匹配班级自动创建（含年级推断）
- **导出模板**：按课表动态聚合的一年级/二年级/三年级三张表（含三年级），合计行 + 中文大写金额

### 6. 加班管理费
- 加班记录（日期/时段/类别/金额）、管理费按月登记（班主任费、教研组长等）
- 补助发放时**都并入「管理」项目**：管理费按月份归属周期（防跨月双计），加班按日期范围

### 7. 补助发放
- **6 个项目**：调课 / 超课时 / 管理 / 夜自习 / 出卷 / 监考
- **每 4 周发放一次**（period_no 自动编号，与超课时/夜自习同周期基准）
- **读取按钮**：从各模块自动拉取本周期金额，可手动修改（修改后标记 manual）
- **导出**：夜自习按年级 3 个 sheet（一年级/二年级/三年级课任教师），其他补助项目按**教师主带年级**拆 3 张表（行=该年级有补助教师，列=该期有数据项目），无课表归属人员的补助进「其他人员」兜底表（不丢数据）；无数据项目不导出
- **手工值保护**：「读取」不会覆盖已手工调整的金额（flash 提示跳过条数），需覆盖时先删该行或传 `force=1`

### 8. 数据管理
- **统一导入**：基础数据（班级/教师/课程/教学任务/课表）+ 夜自习安排表，两大导入入口
- **备份与恢复**：在线备份（SQLite 快照）、全量导出下载、上传备份恢复、恢复/重置前自动备份
- **重置**：输入「清空」确认，清空业务数据（保留管理员账号与系统配置）
- **单项数据删除**：17 类数据（班级/教师/课程/教室/教材/教学任务/课表/征订/发书/请假/夜自习/加班/管理费/停课日/上课日/补助发放/操作日志）——**按类型清空**（当前学期该类，其他数据不受影响）或**单条删除**（列表逐条删，最多 200 条）
- **统计看板**：数据库大小 + 17 类数据数量一览

### 9. 停课/上课日管理（调休补课）
- **双 Tab**：停课日（放假/活动）+ 上课日（调休补课）
- **上课日两种添加方式**：具体日期（选完自动带出星期几确认）/ 星期几规律（周一~周日可多选，本学期内每周该日都算上课日）
- 均为校历台账记录，**不参与有效周计算**（有效周按自然周，放假停课不扣）

### 10. 课时标准
- 职务标准课时可配置（专任教师/教研室主任/中层干部/行政兼课）
- 学科系数已移除（超课时无学科系数，上一节算一节）

### 11. 综合报表（领导专用）
- 领导账号只读首页 + 综合报表，全部 Excel 导出（统一宋体格式）

### 12. 学期管理
- 新建学期可**继承**上学期数据（班级/教师/课程/教室/教材库/教学任务/课表，关联自动重映射）
- 学期切换、重命名、删除（级联清理该学期全部数据）
- 可手动指定有效教学周数（整数）

### 13. 系统设置与账号
- 参数设置：学校名称、每周上课天数、每天节数、各项补助单价
- 操作日志：登录/增删改等操作留痕
- 账号：修改密码、管理员/领导角色

## 🔐 角色权限

| 角色 | 权限 |
|---|---|
| **admin（管理员）** | 全部功能 |
| **leader（领导）** | 只读：首页 + 综合报表（其余页面自动拦截） |

## 🛠 技术架构

- **后端**：Flask 3 + Flask-SQLAlchemy 2 + SQLite（WAL 模式）+ openpyxl（导入导出）+ waitress（生产服务）
- **前端**：Bootstrap 5 + Jinja2 模板，静态资源全本地化（无 CDN 依赖）
- **端口**：5801（可用 `PORT` 环境变量覆盖）
- **数据**：单机 SQLite，备份为完整数据库快照；数据不出局域网

## 🚀 本地运行

```bash
# 安装依赖（详见 requirements.txt）
pip install -r requirements.txt

# 启动（默认端口 5801）
python3 app.py
# 或指定端口
PORT=5802 python3 app.py
```

浏览器访问 `http://<服务器IP>:5801`，首次启动自动创建数据库与默认管理员账号（admin / admin123），**登录后请立即修改密码**。

## 📦 飞牛 fnOS 部署

打包好的 `EduAdmin_*.fpk` 可在飞牛应用中心**手动安装**（应用中心 → 手动安装 → 选择 fpk 文件 → 选卷）。要点：

- 服务端口 5801（manifest 声明），桌面图标自动生成
- 数据库持久化在应用数据目录（TRIM_PKGVAR），**升级/重装不丢数据**（升级时选同一个卷）
- 安装时自动安装 Python 依赖（清华源优先，三重回退）

## 📂 目录结构

```
├── app.py              # 主程序（Flask 单文件，约 5000 行）
├── import_parser.py    # 教务 Excel 导入解析
├── templates/          # Jinja2 模板（36 个页面）
├── static/             # 静态资源（Bootstrap/FontAwesome/Chart.js 本地化）
└── instance/           # 运行数据（数据库/备份，自动生成）
```

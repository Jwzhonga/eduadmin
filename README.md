# 教务管理系统（EduAdmin）

榆中县职业技术学校教务管理系统 —— 基于 Flask + SQLite 的局域网教务管理 Web 应用。

## ✨ 功能模块

| 模块 | 说明 |
|---|---|
| **订书发书** | 按专业（1-6 学期）统一规划征订，导出支持全部/分专业；发放统计按班级汇总 |
| **排课管理** | 班级/教师/教室三视图课表，相互联动；课表以教务处 Excel 上传为准，支持手动调整（冲突检测+提示回滚）；教师按任教科目排序 |
| **调课登记** | 免审批直接添加，顶课教师自动按节数生成补助；统一按「调课」统计 |
| **超课时统计** | 每 4 周一个结算周期，上一节算一节（无学科系数、无小数点），课时标准可配置 |
| **夜自习管理** | 安排表 Excel 导入（自动匹配班级），排班页只读标准表，统计页按周显示/可调整/整日清空；每 4 周结算补助 |
| **加班与管理费** | 加班记录、管理费按月登记，补助发放时并入「管理」项目 |
| **补助发放** | 调课/超课时/管理/夜自习/出卷/监考 6 项目，每 4 周发放一次；从各模块自动读取、可单独修改；导出夜自习（一年级/二年级模板表）+其他项目 |
| **综合报表** | 领导综合报表 + 全部 Excel 导出（统一宋体格式） |
| **数据管理** | 统一导入入口（基础数据/夜自习）、在线备份/恢复/重置、全量导出 |

其他：班级/教师/课程/教室/教材管理、学期管理（继承）、操作日志、全局搜索、多主题。

## 🚀 本地运行

```bash
# 依赖
pip install flask flask-sqlalchemy openpyxl waitress

# 启动（默认端口 5801）
python3 app.py
# 或指定端口
PORT=5802 python3 app.py
```

浏览器访问 `http://<服务器IP>:5801`，首次启动自动创建数据库与默认管理员账号，请登录后立即修改密码。

## 📦 飞牛 fnOS 部署

打包好的 `EduAdmin_*.fpk` 可直接在飞牛应用中心手动安装（端口 5801，数据持久化在应用数据目录，升级不丢数据）。

## 📂 目录结构

```
├── app.py              # 主程序（Flask 单文件，约 4800 行）
├── import_parser.py    # 教务 Excel 导入解析
├── templates/          # Jinja2 模板
├── static/             # 静态资源（本地化，无 CDN）
└── instance/           # 运行数据（数据库/备份，自动生成）
```

## ⚠️ 说明

- 课表/基础数据以教务处 Excel 为准（数据管理 → 统一导入）
- 角色仅「管理员 + 领导」（领导只读报表）
- 所有导入/导出均为本地处理，数据不出局域网
